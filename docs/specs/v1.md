# V1 Implementation Spec

## Goal
Build an offline-first language-learning tracker that can hand over structured lesson context to any AI chat and import strict lesson result data back into local progress.

## Core principles
- Strict schemas for all data contracts.
- One language per `ProgressData` file.
- 15-20 minute lessons.
- Teacher persona continuity with flexible greeting style and fixed closing structure.
- Deterministic scoring with configurable weights and full-history recompute.

## Contracts
- `LearningPlanData`: static curriculum.
- `ProgressData`: mutable learner state.
- `LessonResultData`: strict AI output payload.
- `NextLessonPromptPacket`: self-contained handover packet.

## AI behavior contract
- Start with a short warm greeting in teacher voice using your own words.
- Keep role discipline and polite redirection for off-topic requests.
- Use broader coverage with 4-7 activities in a single lesson.
- Include one fun micro-element linked to lesson topic.
- End lesson with:
  1. Mini recap paragraph.
  2. Two bullets (strengths, next focus).
  3. Single fenced JSON block and no trailing text.

## Result safety
- App validates imported payload against schema.
- On failure, app rejects atomically and generates a repair prompt with exact errors.
- Next-lesson prompt embeds a complete `LessonResultData` template inline (no external schema file dependency).

## Curriculum seed
- German modules from `A1.1` to `B1.2`.
- Immigration-focused topic rotation: office, vacation, relationship, supermarket, public transportation, job search, friends, activities, animals, business.

## Scoring
- Factors: grammar, verbs, vocabulary, fluency.
- User-adjustable normalized weights.
- Historical lessons are recomputed when weights change.

## Test strategy
- Unit tests for core engines and schemas.
- Integration tests with Playwright for end-to-end user flows.
